# Project Rules for AI Assistants

## Mandatory Change Logging Rule
1. For every prompt/chat in this repository, you **MUST** document all changes, updates, additions, and temporary feature disables in `PROJECT_CHANGELOG.md` at the project root (`c:\Users\tsall\Desktop\1st_version\PROJECT_CHANGELOG.md`).
2. **Page & Section Breakdown Format**: Always structure changes clearly under the relevant Page (e.g., `Home Page (/)`) and specific Section (e.g., `Section 1: Top Navigation Bar`, `Section 2: Hero Section`, `Section 7: Footer Section`, etc.).
3. Always append the date, prompt request, affected files, human-understandable section details, and current status table so that any user or developer reading the document can easily understand every change.
